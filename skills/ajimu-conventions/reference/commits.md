# Commit message examples

## Good

```
Preserve verified work across session restarts
```

```
Reject cyclic task dependencies

Roadmaps with a dependency cycle previously stalled the scheduler without a
message. Validation now names the tasks in the cycle; the import tests cover
three-task and self-referencing cycles.
```

```
Document container account setup
```

These subjects are imperative, describe the resulting behavior, and use a body
only to explain the reason and the checks.

## Rewrite these

| Instead of | Write |
| --- | --- |
| `fixed stuff` | `Keep unsaved drafts during status polling` |
| `Updated the code as requested by the assistant` | `Retry transient storage errors once` |
| `WIP` | Commit only coherent, verified steps; describe what works |
| `Add feature (generated with an AI tool)` | `Add CSV export for usage reports` |
| A body ending in `Co-Authored-By: ...` | Remove the trailer; authorship stays with the owner |

## Words that the check rejects

References to AI, artificial intelligence, assistants, LLMs, specific
code-generation products or vendors, "generated by" and co-author trailers.
Ordinary product words such as "data models" or "payment providers" are allowed.
