# Ajimu Conventions

A Claude skill for **verified, documented delivery**. A change is finished only
when it has been checked, documented and committed cleanly, and the history stays
neutral and owned by the author.

## What it gives Claude

- **A finish-a-change checklist:**
  - run the real checks;
  - tick roadmap items only when their exit checks passed;
  - update the changelog and the affected docs;
  - review the diff;
  - write and validate the commit message;
  - commit with the owner's identity without bypassing hooks.
- **Comment rules:** English comments that explain contracts, invariants, failure
  modes and *why*, not syntax. Examples are in `reference/comments.md`.
- **Documentation templates** for a docs index, roadmap items with dated evidence,
  changelog entries and ADRs.
- **Neutral commit messages:**
  - concise English imperative subjects;
  - no references to AI, assistants, code-generation tools or vendors;
  - no `Co-Authored-By` or "generated by" trailers.
- **`check_commit_message.py`,** a dependency-free validator you can also install
  as a `commit-msg` hook.

## Install

### Claude Code (plugin)

```bash
claude plugin marketplace add AjimuZ/ajimu-conventions
claude plugin install ajimu-conventions@ajimu-conventions
```

Inside a session you can use `/plugin marketplace add AjimuZ/ajimu-conventions`
instead. Claude loads the skill when a task matches its description. You can also
invoke it directly as `/ajimu-conventions:ajimu-conventions`.

### Claude Code (personal or project skill)

```bash
git clone https://github.com/AjimuZ/ajimu-conventions
cp -r ajimu-conventions/skills/ajimu-conventions ~/.claude/skills/      # personal
cp -r ajimu-conventions/skills/ajimu-conventions .claude/skills/        # one project
```

### Claude apps

Zip the `skills/ajimu-conventions` folder and upload it as a custom skill in your
Claude settings.

## Commit-message hook

The script needs Python 3.9 or later and no packages.

```bash
python skills/ajimu-conventions/scripts/check_commit_message.py --message "Add CSV export for usage reports"
```

To check every commit, create `.git/hooks/commit-msg` in your repository:

```sh
#!/bin/sh
exec python /absolute/path/to/check_commit_message.py "$1"
```

Ordinary product words such as "data models" or "payment providers" pass. Tool,
vendor and authorship references do not.
